# Tip Pay

pay tips with just 1 click.

## Project Structure

```sh
tip-pay-backend/
├── config/              # Configuration files (e.g., DB connection, Razorpay config)
├── controllers/         # Business logic for each module
├── middlewares/         # Authentication, error handling, etc.
├── models/              # MongoDB schema definitions
├── routes/              # Route handlers
├── utils/               # Utility functions
├── app.js               # Main app file
├── package.json         # Dependencies
└── README.md            # Project documentation
```

## How To Setup

For installation of Dependencies use the command given blow.

```sh
npm install
```

To run the project run commands given blow.

```bash
npm run serve
--or--
npm run start
```

!!!!!important `make sure to visit .env file and make required changes`
